# 参股关系图谱功能设计

## 功能概述

挖掘上市公司和未上市行业龙头参股的相关公司，自动发现关联概念和题材。

---

## 业务场景

### 场景1：上市公司参股挖掘
```
宁德时代（300750）
  ├── 参股 → 某锂电池材料公司（未上市）
  ├── 参股 → 某充电桩公司（上市）
  └── 参股 → 某储能公司（未上市）
  
概念挖掘：锂电池、新能源、储能、充电桩
```

### 场景2：未上市龙头参股挖掘
```
某AI独角兽（未上市）
  ├── 参股 → A上市公司（持股5%）
  ├── 参股 → B上市公司（持股3%）
  └── 参股 → C上市公司（持股8%）
  
概念挖掘：AI、独角兽、股权投资
当AI题材爆发时，A/B/C可能联动上涨
```

### 场景3：多层参股路径
```
公司A → 参股 → 公司B → 参股 → 公司C
  
发现：A和C存在间接关联
当C有利好时，A可能受益
```

## 数据模型

### 参股关系表
```sql
CREATE TABLE investment_relation (
    id BIGINT PRIMARY KEY,
    investor_code VARCHAR(50),        -- 投资方代码（上市公司代码或企业统一信用代码）
    investor_name VARCHAR(200),       -- 投资方名称
    investor_type VARCHAR(20),        -- investor_type: listed/unlisted
    target_code VARCHAR(50),          -- 被投资方代码
    target_name VARCHAR(200),         -- 被投资方名称
    target_type VARCHAR(20),          -- target_type: listed/unlisted
    shareholding_ratio DECIMAL(10,4), -- 持股比例
    investment_amount DECIMAL(18,2),  -- 投资金额
    investment_date DATE,             -- 投资日期
    data_source VARCHAR(50),          -- 数据来源
    created_at DATETIME,
    updated_at DATETIME
);
```

### 概念关联表
```sql
CREATE TABLE concept_relation (
    id BIGINT PRIMARY KEY,
    company_code VARCHAR(50),         -- 公司代码
    concept_name VARCHAR(100),        -- 概念名称
    relation_type VARCHAR(50),        -- 关联类型（direct/indirect/chain）
    confidence DECIMAL(5,4),          -- 置信度
    source VARCHAR(50),               -- 来源
    created_at DATETIME
);
```

## 核心算法

### 1. 概念推导算法
```
输入：参股关系图谱 + 行业分类
输出：公司-概念关联

步骤：
1. 获取公司所有参股关系
2. 分析被参股公司的行业分类
3. 聚合共同概念
4. 计算概念置信度
```

### 2. 龙头识别算法
```
输入：未上市公司列表 + 参股关系
输出：行业龙头排名

步骤：
1. 统计被参股次数
2. 分析参股公司质量（上市公司数量、市值）
3. 计算龙头分数
4. 排名输出
```

### 3. 路径发现算法
```
输入：两家公司
输出：参股路径

步骤：
1. 广度优先搜索
2. 限制路径长度（最多3层）
3. 计算路径权重
```

## API设计

### 查询公司参股关系
```
GET /api/investment/company/{code}
```

### 查询概念关联公司
```
GET /api/investment/concept/{conceptName}
```

### 查询参股路径
```
GET /api/investment/path?from={code1}&to={code2}
```

### 查询行业龙头
```
GET /api/investment/leaders?industry={industry}
```
