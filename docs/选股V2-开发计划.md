## Phase 1：配置中心 + 版本管理（当前）

### 目标
把选股的全部可调参数（阈值 + 8 个因子权重 + 大盘环境系数）从代码硬写改为**数据库存储、版本化管理、运行时内存加载**，并提供前端配置管理界面。

### 设计决策（已确认）
- **存储格式**：整体 JSON 版本化（一条记录存一份完整配置 JSON）
- **配置范围**：`SelectionCriteria` 全部阈值 + 引擎 8 因子权重 + Regime 三系数（weak/strong/neutral）
- **交付**：后端 + 前端一起做
- **建表方式**：EF Core Migration（项目现用 `MigrateAsync`）

### 配置范围边界（重要）
- ✅ 本阶段提取：8 因子顶层权重、Regime 系数、`SelectionCriteria` 所有阈值
- ❌ 暂不提取：各因子内部的分档明细值（如 `ScoreCapital` 里的 100/85/70/55、`LimitUpPenalty` 罚分档）——留待 Phase 6 因子研究阶段，避免本阶段参数爆炸

### 用户睡醒需手动执行的验收
1. 在配好 `appsettings.user.json`（连 RDS）的环境启动 Web：`cd AIStock.Web; dotnet run` —— 启动时 `MigrateAsync` 会自动建 `selection_config` 表
2. 测 API：
   - `GET /api/selection/config/default` 看默认配置
   - `POST /api/selection/config`（body: `{name,version,remark,activate:true,criteria:{...}}`）存并激活一版
   - `GET /api/selection/config` 确认生效
   - `POST /api/selection/screen`（空 body）确认用上了生效配置
3. 前端：菜单「系统/选股配置」编辑→保存→激活→回选股页看结果联动
