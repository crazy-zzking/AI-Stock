# AIStock.Selection — 选股引擎说明

短线弹性品种选股。**埋伏型**思路：规避追高，偏好「低吸、有量、有逻辑」的中小盘成长股。
架构为 **两级漏斗 + 大盘环境调节**，纯 DB 读取 + 内存打分（选股时不调外部接口，数据由 Worker 采集落库）。

## 数据源
- `daily_market_snapshot`：每日快照（盘中由腾讯批量实时刷新、盘后定格）。选股主数据。
- `dragon_tiger` / `dragon_tiger_seat`：龙虎榜及席位。
- `stock_concept_relation`：个股概念/题材（东财核心题材 RPT_F10_CORETHEME_BOARDTYPE）。
- `stock_base.Industry`：行业（东财 F10）。
- 6 大指数实时（上证/深成/创业/沪深300/科创50/北证50）。

## 决策流程

### 0. 大盘环境（先定松紧）`ComputeMarketRegimeAsync`
6 大指数的 **涨跌幅 + 是否站上 20 日线** + 全市场 **涨家占比** → 综合打分定 强 / 中性 / 弱：
- **弱市**：20 日涨幅追高线压到 30%、要求主力 **净流入 > 0**、综合分 ×0.88
- **强市**：综合分 ×1.06
- 中性：不变

### 1. 一级 · 活跃度粗筛 `ActivityScreener`
"要大涨必须近期有量"。命中任一特征即入池，命中越多活跃分越高：

| 特征 | 条件 | 活跃分 |
|--|--|--|
| 温和放量（埋伏首选） | 未涨停 + 涨幅 2~7% + 量比≥1.5 | +35 |
| 资金流入 | 主力净流入 > 0 | +25 |
| 放量震荡 | 振幅≥6% + 量比≥1.5 | +15 |
| 涨停（弱信号，次日易高开） | 当日涨停 | +10 |

### 2. 二级 · 硬过滤（淘汰）`StockSelectionEngine`
- 主力净流入 < 门槛（弱市需 >0）
- 20 日涨幅 > 上限（默认 50%，弱市 30%）→ **追高排除**
- RSI > 70 → **超买排除**
- **传统行业（金融/地产/电力/采矿/建筑/交运等）且 市值 > 500 亿** → 大盘股排除
- （可选）`RequireDragonTiger`：要求当日上龙虎榜

### 3. 二级 · 多因子加权打分（0-100）`StockSelectionEngine`

| 因子 | 权重 | 看什么 |
|--|--|--|
| 资金面 | 0.20 | 主力净流入强度 + **连续净流入**天数 |
| 位置 | 0.18 | 20 日涨幅越低越好（非追高） |
| 技术面 | 0.16 | **均线多头排列 / MACD / RSI（多头·回调到位·超卖反弹）/ 盘中站上均价** |
| 形态 | 0.12 | 突破新高 / 回踩企稳 / 阶梯放量（多日序列 `SequenceAnalyzer`） |
| 活跃度 | 0.10 | 一级粗筛分 |
| 题材 | 0.10 | 命中 **当日热门题材**（活跃股扎堆的概念）|
| 板块 | 0.08 | 所属行业当日 **强度分位** |
| 龙虎榜 | 0.06 | 上榜 + 净买 + 机构/北向/知名游资席位 |

> 技术面已从「MACD 金叉一家独大」改为**多信号综合**：均线多头排列 +30、MACD 金叉/多头 +20/+10、RSI 多头/回调/超卖反弹 +22/16/12、站上均价 +10。

综合分再 **减涨停性质惩罚**（高位连板/追高重罚、低位首板轻罚）**× 大盘环境系数**，排序取 TOP-N。

### 4. 输出与富化
TOP-N → 星级(1-5) → 标签（多头排列 / 风口·题材 / 强势板块 / 主力+X / 超卖反弹 / 站上均价 / 龙虎榜…）→ 核心逻辑文字（`RuleLogicNarrator`）→ 补行业、概念、命中的热门题材。

## 盘中 vs 盘后
- 引擎逻辑相同，区别在读到的快照是「盘中实时态」还是「收盘定格态」（取决于何时跑）。
- 盘中由 `market-snapshot` 任务（`EnableIntraday`）在交易时段每 ~20 分钟用腾讯批量刷新快照。
- 选股结果每次 `/run` 追加进 `selection_result`（历史留存，不覆盖）；选后表现/复盘按收盘数据回测。

## 关键阈值（`SelectionCriteria`，可调）
`TopN=5`、`HealthyRiseMin/Max=2/7%`、`MinVolumeRatio=1.5`、`ShockAmplitude=6%`、`MinMainNetInflow=0`、`MaxRsi=70`、`MaxRise20d=50%`、`MaxTotalMarketCap=500亿`、`ExcludeTraditionalIndustry=true`。
